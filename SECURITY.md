# Security

Do not post passwords, API keys, session cookies, signed OpenID responses or
authentication URLs in public issues. Report suspected vulnerabilities through
GitHub's private vulnerability reporting when enabled. If unavailable, open an
issue requesting a private reporting channel without exploit details or secrets.

Only Keycloak 26.8.1 / Java 21 is currently targeted. Version 0.1.0 is a release
candidate requiring real-account acceptance testing and further review before
production migration. This project is not affiliated with Valve or Keycloak.
